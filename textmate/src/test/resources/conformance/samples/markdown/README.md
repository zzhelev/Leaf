# Leaf

A git client with **first-class** worktree support, for _agent_ workflows.

## Building

1. Install a JDK 25.
2. Run the build:

   ```bash
   export JAVA_HOME="$HOME/jdk-25"   # a full JDK
   ./gradlew build
   ```
